# 🎮 Hangman Game in Python

## 📌 About the Project
Hangman is a simple word-guessing game developed using Python. The player guesses one letter at a time to find the hidden word before running out of attempts.

## 🎯 Project Objective
The objective of this project is to practice basic Python programming concepts by developing an interactive game.

## ✨ Features
- Random word selection
- Letter-by-letter guessing
- Maximum of 6 wrong attempts
- Input validation
- Detection of repeated guesses
- Win and lose messages

## 🛠️ Technologies Used
- Python
- Random module
- Loops and conditional statements
- Lists and strings
- User input and output

## 🚀 How to Run the Project

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

   ```bash
   python hangman.py
   ```

6. Enter one letter at a time to guess the hidden word.

## 🎮 How to Play
1. The game selects a random word.
2. The player guesses one letter at a time.
3. Correct guesses reveal letters in the word.
4. Incorrect guesses reduce the remaining attempts.
5. Guess the complete word before using all 6 attempts to win.
